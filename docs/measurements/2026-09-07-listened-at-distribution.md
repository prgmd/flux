# 청취 시각 분포 실측 (2026-09-07)

명세 5.3과 5.4는 Silver의 `listens_normalized`와 `fact_listens`를 `listened_date`로
파티션하라고 한다. 그 전제가 실제 데이터와 맞는지 확인한 결과다.

대상은 31일치 증분 덤프를 적재한 Bronze 155,713,649행이다.
`listened_at`이 비어 있는 행은 0건이었다.

## 시간 범위

| 항목 | 값 |
| --- | --- |
| 서로 다른 날 | 7,877 |
| 서로 다른 달 | 260 |
| 서로 다른 연도 | 22 |

**31일치 덤프 안에 21.5년어치 청취 기록이 들어 있다.**
제출 시각과 청취 시각이 다른 시계이기 때문이다. 사용자가 다른 서비스의
청취 이력을 가져오면 20년 전 기록이 오늘 제출된다.

## 하루당, 한 달당

| 단위 | 최소 | 중앙값 | 최대 |
| --- | ---: | ---: | ---: |
| 하루 | 7 | 7,477 | 1,299,336 |

가장 큰 달은 2026-08(30,804,369행), 그다음이 2026-09(7,400,715행)다.
덤프가 다룬 기간이 2026-08-08 ~ 2026-09-07이므로, 이 두 달이 큰 것은
"오늘 들은 것을 오늘 제출한" 정상 경로의 결과다.

## 파티션 후보 비교

한 행을 171바이트로 잡았다(활성 24.76GB ÷ 155,713,649행).

| 후보 | 조각 수 | 중앙값 크기 | 최대 크기 |
| --- | ---: | ---: | ---: |
| `listened_date` | 7,877 | 1.2MB | 211.9MB |
| `listened_month` | 260 | 37.4MB | 5,023.5MB |
| `listened_year` | 22 | — | 8,101.5MB |

`listened_date`로 나누면 **7,840개(99.5%)가 10만 행 미만**이고,
그 조각들이 전체의 75.18%인 117,069,353행을 담는다.
조각 하나의 중앙값이 1.2MB다. Parquet의 권장 파일 크기(128MB 안팎)에 한참 못 미친다.

## 판단

**명세의 `listened_date`는 이 분포에 맞지 않는다.** 결정과 근거는
`docs/partitioning.md`에 적었다.

## 재현

```
docker run --rm -v <데이터 루트>:/data ... flux-spark \
  -e FLUX_STORAGE_ROOT=file:///data flux-spark \n  python scripts/analyze_listened_at.py
```

결과는 데이터 루트의 `measurements/listened-at-distribution.json`에 있다.
