검사 시간은 pytest가 보고한 값이며 설치와 대기는 포함하지 않는다. GitHub 기본 작업의 시작은 05:38:49 UTC이고 마지막 dbt 작업의 종료는 05:43:27 UTC다. 첫 실행의 이 구간은 4분 38초이며 GX와 dbt가 병렬이므로 각 검사 시간을 더한 값과 다르다. 다른 환경의 로컬 시간과 GitHub 시간을 동일 자원의 성능 비교로 해석하지 않는다.

기본 검사 한 개의 차이는 `tests/test_explorer_trace.py`의 실제 explorer 표본 검사다. 파일이 없으면 skip하도록 되어 있으며 원본 표본을 GitHub에 올리지 않았다. 로컬 JUnit에서는 이 검사가 통과한 것을 확인했다. 두 환경 모두 Spark와 설치하지 않은 전용 엔진의 범위를 기본 검사 성공으로 세지 않았다. 실제 dbt와 GX는 별도 환경에서 실행했다.

dbt 작업은 기존 전체 생성의 14개 마트와 문서 및 오류 주입, 기간 교체와 재실행 및 삭제, SQL 실패와 실제 프로세스 종료 후 복구, 잘못된 설정의 컴파일 거부 및 전체 실행의 선택 복구를 포함한다. GX는 실제 엔진 검사와 문서 생성, 불량 및 변조와 엔진 예외 및 문서 누락의 결과 전환 차단을 포함한다. 이 작은 제어 입력을 전체 Silver 증분이나 실제 수집 운영의 증거로 사용하지 않는다.

운영 데이터와 조회 대상은 변경하지 않았다. CI의 권한 및 실행 선택은 [CI 문서](../ci.md), 다음 완료 조건은 [확장 계획](../data_governance_plan.md)을 따른다. 브랜치 보호와 관측 기록 통합 및 독립 복원은 후속이다.
