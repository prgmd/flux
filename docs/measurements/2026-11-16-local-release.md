# 53개 증분 덤프와 로컬 운영 조회 전환

11월 13일부터 15일까지 기존 분석본에 받아 둔 ListenBrainz 아카이브 53개를 반영했다. 16일에 검증한 결과를 로컬 릴리스 `2026-11-16`으로 활성화했다.

| 층 | 입력과 검증 결과 |
| --- | --- |
| Bronze | 청취가 없는 아카이브 10개를 포함해 53개를 확인했다. 새 원문 144,061,656줄이 모두 적재됐고 Bronze v12는 306,741,453행이다. 새 원문의 파싱 격리는 0행이었다. |
| 월별 Silver | Bronze CDF 증분으로 154,276,445키와 296,552,210회를 만들었다. 전체 품질 격리는 1,687,097행이다. 월별 집계 CDF는 변경 전후 이미지를 포함해 74,496,904행이며, 영향을 받은 청취 월은 275개다. |
| Gold | 공식 녹음과 크레딧을 재검수한 뒤 전체 재계산했다. 월별 7개와 연간 7개, 합계 183,209,558행의 키와 값이 DuckDB 기준본과 dbt에서 일치했다. 공식 아티스트 귀속 범위는 51,922,229회(17.51%)다. |

## 실제 중단과 재개

11월 13일에 실행을 멈췄을 때 월별 횟수 표만 Delta v1로 커밋돼 있었다. 이 표의 처리 위치는 Bronze v12였으며 메타데이터와 격리는 여전히 v0을 가리켰다. 15일에 이전 작성자가 종료됐음을 확인해 남은 잠금 파일을 사본 밖으로 옮기고, 보조 표 두 개만 Bronze v12까지 이어 처리했다. 이미 커밋된 월별 횟수 표의 지문과 청취 합계는 재개 전후 같았고, 같은 Bronze 버전으로 다시 실행했을 때 세 표에 새 커밋이 생기지 않았다.

DuckDB에서 2002년 10월, 2026년 10월과 11월을 Bronze v12부터 다시 계산했다. 22,086,607개 키와 40,426,875회의 월별 횟수가 일치했다. 전체 Silver에서는 중복 키, 잘못된 횟수나 필수 키, 메타데이터 참조 누락을 검사했고 모두 0건이었다.

Gold 기준 계산은 8GB에서 월별 곡 집계가, 24GB에서 연간 곡 집계가 메모리 부족으로 중단됐다. 월별 완료 결과를 보존하고 완전한 연도 단위의 네 묶음으로 연간 계산을 재개했다. dbt도 같은 연도 경계에서 모델 24개와 검사 145개를 묶음마다 실행했다. 합친 두 결과를 모든 기간과 키로 대조했고, 정수와 문자열은 정확히 비교하고 실수에는 1e-12 허용 오차를 적용했다.

| 측정 항목 | 실측 |
| --- | ---: |
| Bronze 적재와 대조 | 3,018.46초 |
| Silver 재개 구간 | 9,477.18초 |
| Silver 독립 대조 | 1,066.48초 |
| dbt 입력 준비, 실행, 내보내기와 대조 | 5,472.06초 |
| Gold 최종 Parquet 14개 | 6,696,667,202바이트 |

Silver 재개 시간은 중단 전 실행을 제외한다. dbt 시간은 이번 전체 재계산 경로를 잰 값이다. Gold 영향 기간만 교체한 검증은 [10월 통제 변경 6행 실측](2026-10-23-full-silver-cdf-gold.md)에 있다.

## 운영 조회 확인

검증본의 Delta 데이터와 로그, CDF 파일, Gold와 검사 결과를 릴리스 폴더에 복사했다. 2,172개 파일 지문과 Silver 및 Gold 완료 자료를 확인한 뒤 `ops/current_release.json`을 교체했다. 전환 뒤 기본 질의에서 새 Bronze 행 수와 월별 및 연간 Gold의 296,552,210회를 확인했고, 새 경로에서 Bronze v12와 월별 Silver v1의 CDF 일부를 읽었다. 이전 일별 경로를 보존했고 되돌리기 동작은 테스트 사본에서 확인했다. 절차는 [운영 릴리스 조회와 전환](../running.md#운영-릴리스-조회와-전환)을 따른다.

이 릴리스는 수동 전환으로 검증했다. 다음 배치의 Airflow 연결, 실제 7일 연속 운영, 새 덤프에서의 Gold 영향 기간 교체 검증이 남아 있다.
