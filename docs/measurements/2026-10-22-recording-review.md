# 공식 근거와 검수 이력 및 월별 표본 사본 검증

2026-10-22 실측. [검수 절차와 저장 계약](../recording_review.md), [R9](../recording_link_rules.md#r9-공식-id를-확인한-악센트-후보-연결)를 따른다. 원문과 원래 MBID, MSID는 보존한다. 운영 Bronze와 Silver 및 Gold를 수정하지 않았다.

## 범위와 조건

기존 악센트 확장 표본 102행을 공식 MusicBrainz 20260905-002519 스냅샷의 녹음 46개 및 크레딧 17개와 재대조했다. 사용한 recording, artist, artist_credit_name과 recording_gid_redirect 파일의 SHA-256 및 크기를 기존 추출 매니페스트와 확인했다. 공식 아티스트 이름은 artist 표의 대표 이름 기준이다. prepared 데이터베이스는 ID 조회 보조에만 사용하고 현재 활성 Silver 메타데이터는 다시 읽었다. 이전 전체 비교 실험의 완료를 의미하지 않는다.

월별 Silver와 메타데이터의 로그 지문은 입력 표본의 고정 상태와 같았으며 실행 후에도 같았다. 원문 102행에는 서로 다른 MSID 95개가 있으며 그 전체 메타데이터 범위는 138행이다. 같은 최종 비교 이름이며 악센트 제거 전 키가 다른 MSID 쌍을 조사했다. 16개 기존 곡 묶음마다 판정 상태별 최대 3쌍을 후보 ID순으로 선택해 51쌍을 기록했다. 대조용 아티스트 및 문자 보존 사례도 facts.json에 남기며 다른 곡명인 bôa와 BoA를 같은 곡 후보로 꾸미지 않았다. 목적 표본이며 전체 데이터의 정확도나 연결률을 추정하지 않는다.

## 판단 결과

| 최신 판단 | 후보 쌍 수 | 의미 |
| --- | ---: | --- |
| approved | 8 | 공식 근거가 일치한 agent의 실험용 승인 |
| keep_separate | 2 | 공식 녹음 ID가 달라 분리 유지 |
| hold | 41 | 원래 ID 부족 31, 공식 근거 미확인 5, MSID 내부 참조 충돌 5 |

판단 이벤트는 52개다. 한 후보를 초기 보류에서 근거 검토 뒤 실험용 승인으로 바꿔 supersedes 연결도 실제 파일에 기록했다. 이는 두 독립 검수자의 합의가 아니라 한 agent의 판단 수정 이력이다. 사람 승인은 0이며 production 승인 내보내기는 0이다. 사람 검수 주체나 계정을 대신 기록하지 않았다.

연결 가능 쌍에는 Céline Dion의 Parler à mon père/Parler a Mon Pere, Mylène Farmer의 À l'ombre/A l'ombre, Zoé의 Via Láctea 표기와 Björk의 같은 녹음 MBID에 속하는 Jóga/Joga가 포함된다. 반면 Björk의 일반 녹음과 다른 BBC 라이브 참조는 분리 유지 2쌍에 포함된다. Live, Remix와 Sped Up은 버전 문구를 지우지 않으며 다른 녹음으로 유지하는 규칙을 테스트했다.

버전 표기가 없으면 recording:<공식 녹음 MBID>라는 참조 한정 키를 사용한다. 제목에 Live가 없다는 이유로 original 음원이라고 주장하지 않는다. 녹음과 귀속 검증, 원문과 공식 버전 표기의 일치가 별도 조건이다.

## 관측 13개와 MSID 전체 9개는 다르다

8개 승인 쌍에서 중복 관측을 정리하면 관측 매핑은 13개다. 월별 표에는 원래 개별 메타데이터가 없으므로 모든 관련 변형이 같은 대상으로 승인된 MSID만 옮긴다.

| 처리 | 사례 | 이유 |
| --- | --- | --- |
| 월별 연결 허용 | Céline Dion 2개 MSID, Mylène Farmer 2개, Zoé 3개, Björk 2개 | 관련 메타데이터 전체가 같은 공식 녹음과 아티스트 및 버전으로 확인됨 |
| 월별 연결 제외 | ROSALÍA의 15ed6683-5679-48d8-8b55-a4a19abe609c | 같은 MSID에 MBID가 없는 미검수 변형이 있음 |
| 월별 연결 제외 | L'Impératrice의 aa001899-2af2-4cfb-9ee0-d482b91b6e38 | 표본 관측 외의 미검수 메타데이터 변형이 있음 |
| 상대가 없어 제외 | 위 두 사례의 다른 MSID 각 1개 | 전체가 확인된 연결 상대가 없어 단독 변경하지 않음 |

최종 9개 MSID를 4개 녹음으로 묶고 나머지 4개는 원래 MSID 키로 보존했다. 모든 이름 후보를 합친 것이 아니다.

## 저장된 월별 사본 검증

13개 MSID 범위의 월별 기록을 고정 활성 파일에서 읽어 별도 before.parquet로 저장했다. 이 표본의 월별 행 수도 138행이며, 앞의 메타데이터 138행과는 다른 표의 우연히 같은 수치다.

| 항목 | 결과 |
| --- | ---: |
| 변경 전 월별 행 | 138 |
| 변경 후 월별 행 | 137 |
| 변경 전 청취 수 | 245 |
| 변경 후 청취 수 | 245 |
| Python 독립 집계와 저장 결과 키별 불일치 | 0 |
| 같은 고정 입력 재계산 불일치 | 0 |
| 전체 실행 시간 | 64.43초 |

실제 줄어든 한 행은 같은 계정의 2008년 9월 Zoé Via Láctea 기록이다. 두 MSID의 1회와 1회가 같은 녹음 키의 2회가 됐다. 계정 이름은 문서에 공개하지 않는다. 9개 MSID를 4개로 연결했어도 계정과 월이 서로 다르면 월별 행은 줄지 않으므로 행 감소는 1개다. 같은 청취 사건을 제외한 것이 아니며 총 청취 수는 그대로다.

Python은 저장된 before.parquet에서 직접 사전 집계를 만든다. DuckDB가 저장한 after.parquet 및 같은 입력으로 다시 계산한 repeat.parquet와 모든 키 및 횟수를 비교했다. 원본 월별 데이터와 이전 준비 데이터베이스는 읽기 전용으로 사용했다. 출력은 로컬 data/recording-review-20261022-r3이며 원본 데이터 파일은 Git에 포함하지 않는다.

## 테스트와 남은 범위

새 근거 어댑터 5개, 사본 검증 2개, 실제 흐름의 합성 통합 2개와 필수 검수자 지정 CLI 1개를 추가했다. 구현 전 모듈 부재 실패를 확인했고, 실제 실행에서 발견한 대표 이름 및 크레딧 표시 이름 차이와 읽기 전용 DuckDB의 임시 뷰 문제는 각각 실패 재현 뒤 수정했다. 이전 저널 9개와 관련 기존 회귀를 포함해 79개가 통과했다.

실제 사본의 검증 완료와 사람의 사실 검수 완료를 구분한다. 다음에는 review.md와 facts.json의 근거를 사람이 읽고 판단을 추가한다. 미검수 변형이 있는 MSID는 상세 자료로 풀기 전까지 보류한다. FastAPI, 전수 적용, 운영 승격과 Gold 재생성은 이번에 수행하지 않았다. 같은 고정 입력의 재계산 검증을 새 덤프의 증분 중복 가산 방지 검증으로 해석하지 않는다.
