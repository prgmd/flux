# 전체 Silver CDF와 Gold 증분 대조 실측

2026-10-23에 시작한 실험을 2026-10-24에 중단 사본에서 복구해 완료했다. 운영 데이터와 조회 대상은 교체하지 않았다. [전체 실행 및 복구 절차](../full_gold_cdf.md)를 따른다. 이 문서는 이전의 [소형 CDF 종료 및 복구 실험](../silver_cdf_gold.md)과 전체 입력 규모의 통제 변경 실험을 구분한다.

## 입력과 변경 범위

월별 Silver **80,563,985행**, 청취 수 **157,351,363회**와 이전에 전수 대조를 완료한 전체 dbt DB를 기준으로 사용했다. 월별 Delta ID와 시작 및 종료 버전, 원래 Silver 세 표와 기준 Gold 및 프로젝트를 고정했다. 사본의 월별 표에서 실제 Spark MERGE를 실행하고 CDF를 읽었다. 원래 Bronze의 설정과 처리 위치는 유지했다.

Nirvana의 Pennyroyal Tea에서 한 기여를 1회에서 3회로 수정했고 Sentenced의 Her Last 5 Minutes에서 한 기여를 삭제했다. Nirvana의 Stay Away 한 기여는 2010-01에서 제어 월 1990-02로 옮겼다. 기존 곡 Pennyroyal Tea에 제어 계정의 1회도 삽입했다. 수집한 새 덤프나 실제 새 청취의 유입을 뜻하지 않는다. 수정 전과 후 각 2행, 삽입과 삭제 각 1행의 **실제 CDF 6행**을 사용했다.

시작 v0에서 종료 v2로 진전했고 종료는 80,563,985행과 **157,351,365회**다. 영향 월은 2010-01과 1990-02, 연도는 2010년과 1990년이다. 기존 2010년 1월은 85,528행, 2010년 전체는 1,035,094행이다. 곡 사전과 라벨 및 공식 크레딧은 고정했으며 새 MSID와 승인 정책의 확장은 넣지 않았다.

## 전수 대조

시작 Gold 입력은 시작 Silver와 모든 키 및 값이 일치했다. CDF 적용 후 입력도 같은 종료 Silver 버전과 전수 일치했다. 종료 위치에서 같은 범위를 재실행하면 적용 0행이고 dbt를 재실행하지 않았다. 별도 전체 계산 DB는 CDF 적용 결과를 복사하지 않고 종료 버전의 활성 Delta 파일을 직접 읽어 만들었다.

증분 경로는 모델 24개와 검사 145개가 성공했다. 전체 계산 경로는 중단 전 생성된 모델 20개를 재사용하고 미완료 모델 4개를 생성했으며 검사 145개를 모두 다시 통과했다. 이전 모델의 성공 로그와 manifest, 실행 SQL 및 현재 프로젝트를 대조했고 복구한 입력 80,563,985행도 고정 종료 Silver와 다시 전수 대조했다. 재사용 20개와 복구 실행 149개가 원래 169개 노드를 정확히 포함하는지도 별도로 확인했다.

최종 **Gold 14개의 모든 기간과 키 및 컬럼이 전체 재계산과 일치**했다. 변경하지 않은 기간도 이전 전체 Gold와 전수 일치했다. 정수와 문자열은 정확 비교하고 부동소수는 기존 계약의 절대 및 상대 허용 오차 `1e-12`를 적용했다. 원본 Silver의 파일 지문과 Delta 버전, 기준 DB 및 실행 프로젝트는 실행 뒤에도 같았다. 모든 확인 후에만 사본의 완료 처리 위치를 저장했다.

## 시간

아래는 총경과 시간이다. 연간 곡 내보내기와 복구 세션 전체에는 약 77분의 대기 모드 구간이 포함된다. 전원 상태의 상세는 뒤의 별도 구역을 따른다.

Python 3.11.9의 별도 환경에서 DuckDB 1.5.5, dbt-core 1.11.16과 dbt-duckdb 1.11.0을 사용했다. dbt 작업은 1개, 엔진 스레드는 2개, 메모리는 16GB이며 중간 모델 6개는 테이블이다. CDF 생산에는 Spark 4.2.0과 delta-spark 4.4.0을 사용했다.

증분 dbt build와 검사 전체는 **47.34분**이다. 그 노드 시간 합은 모델 790.113초와 검사 1,981.566초이며 프로세스 전체에는 시작과 종료 등의 비용도 있다. CDF SQL 적용 시간만으로 전체 갱신 시간을 대신하지 않는다. 현재 중간 모델 6개와 데이터 검사는 증분 경로에서도 전체 입력을 처리한다. 최종 기간 교체는 구현했지만 모든 연산이 변경량에 비례하는 구조는 아니다.

전체 재계산은 검사 도중 프로세스가 종료돼 **연속 실행 시간은 미측정**으로 남긴다. 종료 원인은 확인되지 않았다. 모델 20개 생성과 이전 검사 일부에 쓴 시간은 복구 세션 표에 포함하지 않는다. 중단 로그의 시각 차이나 모델 시간 합으로 전체 재계산 시간을 대체하지 않으며 두 경로의 속도 배수를 제시하지 않는다. 복구 세션은 **158.39분**으로, 시작 전 기준 파일 확인과 Python 기동은 제외한다. 사본 준비와 Spark 시간도 별도이며 JVM 기동은 Spark 구간에 포함하지 않는다.

첫 소비 시도 r1은 작은 질의에서 발견한 최종 파일 비교문의 DuckDB 바인딩 오류를 고치기 위해 dbt 시작 전에 통제 중단했다. 해당 사본은 보존했으며 성공 구간 시간에 합치지 않는다. 다음 r2의 실제 실행 중단과 오늘 복구는 그 첫 시도와 구분한다. 전수 검사 범위를 줄이지 않고 완료 모델만 재사용했다. 캐시와 실행 순서의 영향을 통제한 반복 벤치마크나 대량 CDF 처리율 측정은 아니다.

## 테스트와 다음 범위

복구 검사 12개와 관련 회귀 57개가 통과했다. 기본 최소 개발 환경은 1,018 passed, 21 skipped, 12 deselected와 82.70초다. 로컬의 미추적 식별 초안과 전용 표본 검사도 수집될 수 있으므로 깨끗한 원격 검사 수와 구분한다. 새 검사 없는 상태의 ImportError를 먼저 확인했고 완료 상태와 중복 복구, 잘못된 로그 및 manifest, SQL 변경을 차단했다. 실제 전체 실행은 이 단위 검사와 별도로 검증했다. 실제 CDF를 생산하는 작은 Spark 검사와 앞선 전체 생산 결과는 유지했고 이번에는 Gold 복구에 집중했다.

새 덤프 전체를 Bronze부터 Silver로 갱신하는 운영 연결, 대량 CDF 처리율, 새 MSID와 버전 고정 승인 매핑 입력, 실제 보존 기간 만료와 7일 연속 운영은 남아 있다. 전체 규모에서 모든 실패 지점을 새로 주입한 것은 아니며 앞선 소형 사본의 두 강제 종료 근거와 이번 실제 중단 사본의 복구를 구분한다. 곡 버전과 공식 귀속의 미확인 사례 검수도 별도다. 다음은 영향 기간 계산의 비용 개선 검토와 관측 및 독립 복원, 데이터 카탈로그 및 Airflow와 실제 연속 운영이다.


## 전원 상태와 총경과 구분

Windows 전원 이벤트에는 13:11:22부터 14:28:41까지 Modern Standby 구간 4,638.443초, 약 77.31분이 기록됐다. 위 복구 세션 총경과와 증분 연간 곡 내보내기 시간에는 이 구간이 포함된다. 이 값을 순수 처리 성능으로 해석하지 않는다. 전원 상태 구간 전체가 CPU 정지 시간과 같은지 측정하지 않았으므로 자동으로 빼서 활성 처리 시간으로 표시하지 않는다. 현재 실행에는 임시로 화면과 시스템 활성 요청을 함께 걸었고 공통 함수도 보완했다. 전원 계획은 바꾸지 않았고 종료 시 요청을 해제한다. [실행 상태 요청](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-setthreadexecutionstate)을 따른다.

이 보완에는 전원 요청 검사 3개를 추가했다. 기존의 켜기 요청이 화면 활성 비트를 빠뜨려 먼저 1 failed와 2 passed를 확인했고 수정 뒤 관련 최종 회귀 60개가 3.74초에 통과했다. 앞 절의 로컬 기본 회귀 1,018개는 전원 요청 보완 전 실행이다.


## 중단 복구 추가 후 자동 검사

복구와 전원 요청을 보완한 코드 b709479의 [실행 40066890815](https://github.com/prgmd/flux/actions/runs/40066890815)에서 기본 1,017 passed, 22 skipped, 12 deselected와 17.00초, dbt 7 passed와 269.77초, GX 11 passed와 11.37초가 확인됐다. 새 복구 검사 12개와 전원 요청 검사 3개를 포함한다. 전체 Silver 대조는 로컬 명시 실행이며 이 CI에 포함하지 않는다.
