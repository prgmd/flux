# Silver 첫 생성 실측 (2026-09-14)

Bronze 155,713,649행을 읽어 `silver.listens_normalized`를 만들었다.
S3 소단위 1~4에서 정한 판단 넷을 엮은 첫 실행이다.

## 대조

| 항목 | 값 |
| --- | ---: |
| Bronze | 155,713,649 |
| Silver | **151,192,624** |
| 격리 | **0** |
| 중복 제거 | **4,521,025 (2.9034%)** |
| 생성 시간 | 2,877초 (48분) |
| 파티션(달) | 260 |

**두 번 독립적으로 잰 값이 정확히 일치한다.**

| | 측정 스크립트 (`groupBy`) | 적재 잡 (윈도 함수) |
| --- | ---: | ---: |
| 서로 다른 키 | 151,192,624 | 151,192,624 |
| 지워질 행 | 4,521,025 | 4,521,025 |

`measure_duplicates.py`는 `groupBy` 집계로, `build.deduplicate`는 `row_number()`
윈도 함수로 계산한다. **다른 코드 경로가 같은 답을 냈으므로 둘 다 틀렸을
가능성이 크게 줄었다.**

격리 0건도 예측대로다(`2026-09-14-quality-rules.md`).

## MBID 해석 결과

| `mbid_source` | 행 | 비율 |
| --- | ---: | ---: |
| MAPPING | 29,562 | 0.02% |
| CLIENT | 4,150,196 | 2.74% |
| LASTFM | 49,512,422 | 32.75% |
| NONE | 97,500,444 | 64.49% |
| **MBID 있음** | **53,692,180** | **35.51%** |

### 빈 문자열 40건이 정확히 빠졌다

`mbid_resolution.md`가 예측한 `MAPPING`은 29,602였다. 실제는 **29,562**로
정확히 **40** 적다.

그 40이 품질 실측에서 찾은 **빈 문자열 40건**이다
(`2026-09-14-quality-rules.md`). 형식 검증이 의도대로 빈 값을 걸러
`NONE`으로 밀어낸 것이 숫자로 확인됐다.

### 중복 제거가 MBID를 거의 안 잃었다

`deduplication.md`에 빈칸으로 남겨 둔 질문의 답이다.

| | MBID 보유율 |
| --- | ---: |
| 중복 제거 전 (Bronze) | 35.54% |
| 중복 제거 후 (Silver) | **35.51%** |

**452만 행을 지우면서 MBID 보유율은 0.03%p만 떨어졌다.**

"나중 덤프를 남긴다"로 했으면 12.9%의 중복 키에서 필드를 잃었을 것이므로,
MBID 우선 규칙이 실제로 일했다고 볼 수 있다.

다만 **두 규칙을 나란히 돌려 비교한 것은 아니다.** 지금 수치는
"MBID 우선 규칙이 보유율을 지켰다"까지만 말한다.

## 용량

| 테이블 | 크기 |
| --- | ---: |
| `bronze.raw_listens` (활성) | 24.76GB |
| `silver.listens_normalized` | **19GB** |
| `silver.invalid_listens` | 14KB |

`raw_json`을 버렸는데도 24.76GB에서 19GB로 **23%밖에 줄지 않았다.**

원본 문자열을 버린 대신 파싱한 컬럼 18개가 들어갔기 때문이다. `artist_mbids`
배열, `track_name`, `artist_name`, `release_name` 같은 문자열이 차지한다.

> Bronze에서 컬럼 지향 압축이 `raw_json`의 반복되는 키 이름을 잘 잡아냈던 것을
> 생각하면, **압축된 원본을 버리고 펼친 값을 넣는 것이 늘 이득은 아니다.**
> 다만 Silver의 목적은 용량이 아니라 **읽을 때 파싱하지 않는 것**이다.

## 남은 일

- **파티션 키 결정을 시간으로 확인한다.** 하루 질의 시간, `ZORDER` 효과,
  큰 달 재작성 시간. 지금은 조각 수와 크기만 보고 정한 잠정이다
  (`docs/partitioning.md`)
- **48분은 재실행하기에 길다.** Silver는 중복 제거가 덤프를 걸쳐 작동해
  전체를 다시 만든다. 증분으로 만들 수 있는지는 별도 판단이 필요하다
